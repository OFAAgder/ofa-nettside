# Samarbeidsrutine – OFA nettside (to brukere)

## Grunnprinsipp
Kun én person jobber på koden/innholdet om gangen. Gi hverandre kort beskjed (SMS/Teams/e-post) når dere starter og avslutter en økt.

## Før du starter en økt
1. Åpne prosjektmappen i Claude Code.
2. Be Claude Code hente siste versjon fra GitHub ("hent siste endringer" / `git pull`) – gjør dette hver gang, selv om du selv var sist til å jobbe.

## Under økten
3. Beskriv ønsket endring i vanlig språk til Claude Code (f.eks. "bytt teksten under Om OFA", "legg til bilde på forsiden").
4. Se gjennom resultatet i nettleseren før du går videre til neste endring.
5. Gjør helst én side/seksjon ferdig om gangen – lettere å følge med og rette opp.

## Når du avslutter en økt
6. Be Claude Code lagre og sende endringene til GitHub ("committ og push") med en kort beskrivelse av hva som ble gjort.
7. Gi beskjed til den andre at nye endringer er lagt ut, slik at de henter siste versjon før de starter selv.

## Hvis dere må jobbe samtidig
- Avtal på forhånd hvem som jobber på hvilken side, slik at dere ikke endrer samme fil samtidig.
- Oppstår det en konflikt i GitHub – ikke prøv å løse den selv. Spør Claude Code om å løse den trygt.

## Enkel kommunikasjonsregel
Kort melding ved start og slutt av hver økt, f.eks.:
- "Starter å jobbe på Kontakt-siden nå."
- "Ferdig, endringene er lagt ut på GitHub."
